CACO SERVICES — CLEAN GITHUB WEBSITE

IMPORTANT: Upload the CONTENTS of this folder, not the ZIP file itself.

Recommended method (GitHub Desktop):
1. Clone your existing GitHub Pages repository using GitHub Desktop.
2. In GitHub Desktop choose Repository > Show in Explorer.
3. Keep the .git folder (hidden) and DO NOT delete the repository itself.
4. Remove old website files from the repository working folder EXCEPT .git.
5. Copy ALL contents of this clean website folder into the repository folder.
6. Check that index.html, images/, services/, styles.css, and CNAME are at the ROOT.
7. GitHub Desktop > Commit to main > Push origin.
8. Wait for GitHub Pages deployment, then open https://www.cacoservices.ca and hard refresh (Ctrl+Shift+R).

Do not delete your GitHub repository or change your DNS settings.
Do not upload individual images at the repository root.
If GitHub Pages is configured to publish from /docs, switch it to / (root) or place the files in the configured publishing folder.

Note: Existing main-service photos derived from reference screenshots may remain less sharp than original high-resolution photographs.
